# Building an API feature on AxilJS

Follow the project layout `axil create` generates: `src/modules/<name>/{controllers,services,entities}/` plus `<name>.test.ts`, entry `src/main.ts`. Inside this monorepo, examples live in `examples/src/`.

## 1. Routes: `@axiljs/core`

```ts
import { Application, Router, cors } from '@axiljs/core'

const app = new Application({ server: { port: 3000 } })
app.use(cors({ origin: ['http://localhost:5173'] }))

const users = new Router()
users.get('/', listUsers)
users.get('/:id', getUser)          // relative path: mount() strips the prefix
users.post('/', validate({ body: CreateUser }), createUser)
app.mount('/users', users)

app.listen()
```

- Handlers are `(req, res, next?)`. `req.params`, `req.query` (repeated keys become arrays), `req.body` (parsed JSON/form/text, 1 MB limit, 413 beyond), `req.locals` (per-request bag; auth puts the user at `req.locals.user`).
- Respond with the envelope helpers, not raw `res.json`: `res.success(data, msg?)`, `res.created(data)`, `res.paginated(...)`, `res.noContent()`, `res.badRequest(msg)`… Shape: `{status, code:'HTTP_200_OK', message, data}`.
- Signal errors by **throwing** `@axiljs/common` errors (`NotFoundError`, `BadRequestError`, `ForbiddenError`, `ValidationError`…), which core maps to the right status and `{error:{code,message}}`. Don't hand-roll error JSON.
- Precedence: static segment > `:param` > `*`.

## 2. Validation: `@axiljs/validation`

```ts
import { v, validate } from '@axiljs/validation'

const CreateUser = v.object({
  name:  v.string().min(2).max(100),
  email: v.string().email(),
  tags:  v.array(v.string()).default([])
})
```

`validate({ body, params, query })` replaces `req.body`/`req.params`/`req.query` with the parsed output (defaults applied, `.strip()` honoured) or responds 422. Params and query arrive as strings; `v.number()` accepts numeric strings for validation, but **`trim()` and number coercion are not applied to the output**. Convert explicitly if you need a number.

## 3. Auth: `@axiljs/auth`

```ts
import { JWT, authenticate, requireRole, requireOwnership, hashPassword, verifyPassword } from '@axiljs/auth'

const jwt = new JWT(process.env.JWT_SECRET!)          // ≥ 32 chars, HS256
const token = jwt.sign({ sub: user.id, role: 'admin' }, { expiresIn: 3600 })

users.delete('/:id', authenticate(jwt), requireRole('admin'), deleteUser)
users.put('/:id', authenticate(jwt), requireOwnership('id'), updateUser)
```

Passwords: `await hashPassword(pw)` / `await verifyPassword(pw, hash)` (async scrypt; never store plaintext). Pair login routes with `rateLimit({ max: 5, windowMs: 15 * 60_000 })` from `@axiljs/security`.

## 4. Persistence: `@axiljs/orm`

Prefer the repository style for new code:

```ts
import { createConnection, Entity, Column, PrimaryKey, BaseRepository } from '@axiljs/orm'

@Entity('users')
class User {
  @PrimaryKey() id!: number
  @Column({ type: 'string', length: 255 }) name!: string
  @Column({ type: 'string', unique: true }) email!: string
}

const db = await createConnection({ driver: 'sqlite', filename: './dev.db' })   // postgres/mysql: { driver, url }
class UserRepository extends BaseRepository<User> { constructor() { super(User, db) } }
```

Before relying on a method, read `packages/orm/src/repository/base-repository.ts` for the exact signatures (`find`, `findOne`, `findById`, `create`, `update`, `delete`, `paginate`).

**Security rule:** the ORM does **not** quote identifiers. Never pass user input as a column name to `where`, `orderBy` or `select`; map it through a whitelist (`const SORTABLE = { name: 'name', created: 'created_at' }`). Values are parameterized and safe.

Schema changes go in migrations (`Schema` + `MigrationRunner`); use `.timestamps()` for created/updated columns.

## 5. Tests: `@axiljs/testing` (or vitest inside this monorepo)

```ts
import { createTestClient } from '@axiljs/testing'
const client = createTestClient(app)
const res = await client.post('/users').set('authorization', `Bearer ${token}`).send({ name: 'Ada', email: 'a@x.io' })
expect(res.status).toBe(201)
```

Cover the happy path, a 422 (bad body), a 401 (no token), a 403 (wrong role or owner) and a 404.

## 6. Optional cross-cutting packages

`@axiljs/observability` (`observabilityMiddleware` + `metricsHandler` on `/metrics`), `@axiljs/events` (emit domain events after writes), `@axiljs/queue` (offload slow work), `@axiljs/circuit` (wrap outbound HTTP calls), `@axiljs/cloud` (`multiTenancy`, `auditLog`). Read the package README before using one.
