# Security Policy

## Supported versions
Only the latest published version of each `@axiljs/*` package receives security fixes.

## Reporting a vulnerability
**Please do not open a public issue for security problems.**

Report privately using one of these:
- GitHub: **Security** tab → **Report a vulnerability** (private advisory)
- Email: **tariq@syntaxility.dev**

Please include the affected package and version, steps to reproduce, and the impact.

## What to expect
- Acknowledgement within **3 working days**.
- A fix or mitigation plan within **30 days** for confirmed issues.
- Credit in the release notes, unless you prefer to stay anonymous.
