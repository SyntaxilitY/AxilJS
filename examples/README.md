# AxilJS examples

Each folder here is a complete application generated by the AxilJS CLI from one of its templates:

```bash
axil create <name> --template <template>
```

They are committed exactly as `axil create` writes them, so they double as the reference output of each template. Every example has its own README (endpoints, configuration, project layout) and a test suite.

| Example | Port | Shows | Packages |
|---|---|---|---|
| [`minimal`](minimal/) | 3000 | Routing, validation, error handling, tests | core, config, validation |
| [`rest-api`](rest-api/) | 3001 | Bookstore API: SQLite + migrations, JWT auth, RBAC, pagination, metrics | core, orm, auth, validation, security, observability |
| [`realtime-chat`](realtime-chat/) | 3002 | WebSocket rooms, presence, history, browser client | core, websocket, events |
| [`background-jobs`](background-jobs/) | 3003 | Job queue with retries, timeouts and cancel; cron; circuit breaker | core, queue, circuit, observability |
| [`ai-assistant`](ai-assistant/) | 3004 | Chat, SSE streaming, RAG over Markdown, agent with tools | core, ai |
| [`saas-api`](saas-api/) | 3005 | Tenants, per-tenant rate limits, feature flags, quotas, audit, decorators | core, cloud, auth, decorator |

## Run one

Inside this monorepo the examples are npm workspaces, so `@axiljs/*` resolves to the local packages in `packages/`. No separate install is needed after `npm install` at the repo root.

```bash
cd examples/rest-api
cp .env.example .env          # PowerShell: Copy-Item .env.example .env
npm run migrate               # only for examples with a database
npm run dev                   # axil run: compile, start, restart on save
npm test                      # axil test
```

## Regenerate after changing a template

Templates live in `packages/cli/src/templates/<id>.ts`. To refresh an example from its template, run this from this folder:

```bash
node ../packages/cli/dist/cli.js create <id> --template <id> --yes --skip-install --force
```

`--force` writes over the existing files; delete any file the template no longer produces.
